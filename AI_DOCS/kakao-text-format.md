# Kakao Open Chat Text Format

> 클라이언트가 준 슈미트 베개커버 공고를 표준 템플릿으로 가공.
> `generate_announcement` tool은 이 형식을 *정확히* 따라야 함.

---

## §1 — Stage 1: 모집 시작 공고

### 표준 템플릿

```
🎅 [매장명] & [브랜드명] 오늘의상품 [최저가]원
🎁 [상품 전체명, 단위 포함]

❌ 시중가: [비교가격]원대
🌈 [매장 줄임말] 특가 👉 [최저가]원 🔥

[감성적 설명 라인 1 - 사용 상황/계절감] 💤
[감성적 설명 라인 2 - 사용감 강조] 😌
[감성적 설명 라인 3 - 필요성 강조] 💦
[추가 정보 - 세트 구성] 🛏️

📐 [규격 정보]
🧊 [핵심 소재 정보]
🧵 [추가 소재 정보]

😍 역대급 가격으로 [상품 카테고리] 득템!

❌ 수량소진시 조기 마감 ❌

⏳ 예약 마감일 : [날짜] [시간]
🚚 입고 예정일 : [날짜]
🚩 수령 마감일 : [날짜] 까지
🚩 수령 마감일이 지나면 자동 취소됨을 알려드립니다.

🔴 예약시 상품명 적어주세요 🔴
✅ 예시) [상품 줄임말] 1세트 + 휴대번호 4자리
```

### 실제 예시 (클라이언트 제공)

```
🎅 판다팜 & 산타 오늘의상품 8,900원
🎁 슈미트 냉감 쿨 베개커버 세트(2장)

❌ 시중가: 40,000원대
🌈 산타가족 특가 👉 8,900원 🔥

🧊 이제 쿨하게 숙면하는 여름밤! 💤
😌 머리에 땀 안 차는 시원한 잠! 
💦 여름철 베개커버 위생관리 필수!
🛏️ 2장 세트 번갈아 세탁 사용!

📐 66×40cm 표준 베개 사이즈!
🧊 폴리에틸렌 51% 냉감 핵심소재!
🧵 폴리에스터 49% 부드러운 촉감!

😍 역대급 가격으로 냉감베개 커버 득템!

❌ 수량소진시 조기 마감 ❌

⏳ 예약 마감일 : 05월 07일(목) 오후 2시
🚚 입고 예정일 : 05월 09일(토)
🚩 수령 마감일 : 05월 13일(수) 까지
🚩 수령 마감일이 지나면 자동 취소됨을 알려드립니다.

🔴 예약시 상품명 적어주세요 🔴
✅ 예시) 베개커버 1세트 + 휴대번호 4자리
```

### 변수 매핑

| 템플릿 변수 | DB 필드 | 비고 |
|---|---|---|
| `[매장명]` | (env or settings) | 예: "판다팜" |
| `[브랜드명]` | (env or settings) | 예: "산타" |
| `[최저가]` | `products.price` | 천단위 콤마 |
| `[상품 전체명]` | `products.name` | 단위 포함 |
| `[비교가격]` | `products.compare_price` | 천단위 + "원대" |
| `[감성적 설명]` | AI 생성 (description 기반) | 3-4줄, 이모지 시작 |
| `[규격 정보]` | AI 생성 | 사이즈/용량 |
| `[핵심 소재 정보]` | AI 생성 | 소재 강조 |
| `[예약 마감일]` | `products.order_deadline` | "MM월 DD일(요일) 오전/오후 H시" |
| `[입고 예정일]` | `products.pickup_date` | "MM월 DD일(요일)" |
| `[수령 마감일]` | `products.pickup_deadline` | "MM월 DD일(요일) 까지" |
| `[상품 줄임말]` | AI 생성 | 짧게 (예: "베개커버") |

### 이모지 규칙

- 줄 시작 이모지는 *내용과 의미적으로 연결*되어야 함
- 시원함/냉감 → 🧊 ❄️ 💦
- 잠/숙면 → 💤 😌 🛏️
- 음식 → 🍳 🥘 🍚
- 시간/마감 → ⏳ 🚩
- 배송/입고 → 🚚 📦
- 강조 → 🔥 😍 ❌ ✅

이모지 자동 선택 가이드는 Claude API 프롬프트에서 처리.

## §3 — Stage 3: 수령 안내 공고

### 표준 템플릿

```
📢 오늘 수령 가능 상품 안내

🎁 [상품명 1]
🎁 [상품명 2]
🎁 [상품명 3]
🎁 [상품명 4]

늦지 않게 방문해 주세요! 🏃 💨
감사합니다! 🥰
```

### 실제 예시 (클라이언트 제공)

```
📢 오늘 수령 가능 상품 안내

🎁 스팟 크림
🎁 롤케이크
🎁 주름패치
🎁 냉감패드

늦지 않게 방문해 주세요! 🏃 💨
감사합니다! 🥰
```

### 변수 매핑

| 템플릿 변수 | 데이터 출처 |
|---|---|
| `[상품명 N]` | 오늘 `pickup_date == today` 인 상품 목록 |

조회 쿼리:
```sql
SELECT name FROM products 
WHERE pickup_date = CURRENT_DATE 
  AND status = 'arrived'
ORDER BY name;
```

## 검증 체크리스트

`generate_announcement` tool의 출력은 다음을 만족해야 함:

- [ ] 첫 줄에 매장명 + 가격 (Stage 1만)
- [ ] 이모지가 각 줄 의미와 연결됨
- [ ] 모든 날짜가 `MM월 DD일(요일)` 형식
- [ ] 마지막에 예약 방법 안내 (Stage 1만)
- [ ] 줄 사이 빈 줄 적절히 (3-4줄마다)
- [ ] 총 길이 1,000자 이내 (카카오톡 가독성)
